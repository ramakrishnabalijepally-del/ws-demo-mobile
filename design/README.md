# design/

Client design source material for the WorkSettle mobile app. **Read this folder
before building any screen** — `.agents/rules/08-design.md` treats it as the
visual source of truth.

Expected contents:

| File | Status |
| --- | --- |
| `Platform design.pdf` | 7 pages, supplied 2026-09-08 — the fallback source |
| Figma file / link | **final source of truth** — pending |
| Figma screenshots from the client | pending |
| Logo vector export | pending — never redraw the logo |
| Feature icon assets | pending — see `01-stack.md` on icons |

Anything still marked pending is listed under **Requires verification** in
`.agents/rules/08-design.md`. Do not estimate those values from a PDF render —
ask.

Design *assets* the app actually ships (logo, icons, images, fonts) belong in
`assets/` and are declared in `pubspec.yaml`. This folder is reference material
only.
